# Fortivum — Pix Copia e Cola

Projeto Android Java para Codemagic. A tela de pagamento usa apenas Pix Copia e Cola, sem QR Code.

**Editar código Pix:** `app/src/main/assets/pix/copia_e_cola.txt`.

**Suporte:** `igorddsiqueira85@gmail.com`.

**Importante:** o botão de pagamento não confirma automaticamente a transação; a ativação da licença depende do backend PHP existente e da confirmação manual.

Envie o conteúdo deste projeto para a raiz do GitHub e compile pelo Codemagic usando `codemagic.yaml`.
